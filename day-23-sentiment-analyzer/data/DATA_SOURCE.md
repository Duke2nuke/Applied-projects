# Data source

The three files in this folder are the **Sentiment Labelled Sentences**
dataset, used unchanged:

- `amazon_cells_labelled.txt` — 1,000 Amazon product-review sentences
- `imdb_labelled.txt` — 1,000 IMDb movie-review sentences
- `yelp_labelled.txt` — 1,000 Yelp restaurant-review sentences

Each line is `<sentence>\t<0|1>` where 1 = positive, 0 = negative.

Source: UCI Machine Learning Repository,
https://archive.ics.uci.edu/dataset/331/sentiment+labelled+sentences

Citation: Kotzias, D., Denil, M., De Freitas, N., & Smyth, P. (2015).
"From Group to Individual Labels using Deep Features", KDD 2015.
